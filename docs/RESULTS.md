## Original constraints

The accepted tests retain approximately5.221kg Z1 mass, original joint/motor limits, a20N jaw-force guard, original body fall guards and bounded recovery. No parcel binding, runtime pose writes, between-order world reset or rescue forces are used. The camera/range data and the parcel are generated by the simulator.

The original dual and far-shelf full videos end at364.0s and247.0s sampling instants, while the physical traces end at364.070s and247.155s. The dynamic video ends at37.0s and its trace at37.170s. The unsampled fractions are not synthesized.

## Latest development status

The final goal is a configurable multi-dog warehouse with continuous replenishment and multiple batches. The current shared physical runtime is still two robots. The six-order development sequence has not passed.

The latest attempt ran146.635s and stopped during the first robot's placement preapproach when measured jaw total force reached31.585529N, above the unchanged20N guard. The second robot had reached the receiving station and begun grasping. That attempt's complete postprocessing was paused at the user's request; it is not used as a successful portfolio demo.

Separate local improvements in staging/loaded stopping do not replace full six-order acceptance. Eight independent evaluation environments are not eight robots sharing a warehouse. Historical policy-training survival scores are not used here as reliability claims.

## Evidence layout

- `evidence/<demo>/acceptance.json`: original verdict/metrics with only machine/user path prefixes redacted; original report hash retained.
- `measurements_200hz.jsonl.gz`: derivative, complete-rate projection containing both robots' root states, body/force guards, phases and parcel state. Large leg/action arrays and raw RGB-D/range streams are omitted.
- `projection_manifest.json`: original raw-trace hash, derivative hash, exact coverage and field scope.
- `auditors/`: captured original independent-auditor sources. Some expect the full original run directory, which is not included here; the public projection is checked separately by `scripts/verify_release.py`.
- `recorded_configuration.json`, `original_source_manifest.json`: recorded settings and captured source hashes.
- `docs/media/media_manifest.json`: exact source/output hashes, edit ranges, video frame counts and playback declarations.

The complete development archive remains local. This public repository deliberately contains the necessary runtime, model files and selected evidence rather than the full training/cache archive.
