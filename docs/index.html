How the system works

From parcel recognition to delivery.

01 / PERCEIVERGB-D + ranges

Read parcel codes, locate grasp targets and build a local occupancy map.

02 / COORDINATEOrders + paths

Assign deliveries, reserve shared areas and plan routes with A*.

03 / MOVEAdapted Go2 gait

A pretrained locomotion policy adapted with PPO handles walking with the mounted arm.

04 / HANDLEZ1 + force feedback

Inverse kinematics, gripper-force feedback and support control handle pickup and placement.

What's next

Our goal is a configurable fleet of robot dogs that can work independently in parallel. Parallel operation and long-duration tasks remain the main challenges, and we'll continue to update the repository as the system develops.
